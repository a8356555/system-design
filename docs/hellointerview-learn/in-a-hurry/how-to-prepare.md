# How to Prepare for System Design Interviews
> 來源：https://www.hellointerview.com/learn/system-design/in-a-hurry/how-to-prepare ｜ 分類：in-a-hurry

## 一句話重點
先打地基（理解面試形式、選定 delivery framework、讀 Core Concepts / Key Technologies / Patterns），再大量「自己動手答題→看解答→真人模擬」；主動練習的記憶效果約為被動閱讀的 10 倍。

## 核心內容
### 準備方式
- 想要明確順序 → 跟著課程；想自己挑 → 用本頁計畫。

### Build a Foundation
1. 理解 system design interview 是什麼（讀 intro 或看 mock interview 影片）。
2. 選定 delivery framework：面試節奏快，需要清楚路線圖來線性思考、避免 scope creep，面試當天就照它設計。
3. 學基礎：讀 Core Concepts、Key Technologies、Common Patterns，建立 mental model。

### Practice
原文稱「主動做比被動看多記 10 倍」。流程：
1. 從題目清單選一題
2. 讀需求
3. 自己先答（Guided Practice 或 Excalidraw 等白板）
4. 答完才看 answer key 比較
5. 熟練後找目標公司的人做 peer mock——口頭在時間壓力下講設計是另一種技能

### 題目難度分級（原文清單）
- Easy：Bitly、Dropbox、Yelp、Local Delivery Service
- Medium：Ticketmaster、Instagram、FB News Feed、Tinder、LeetCode、WhatsApp、Strava、Distributed Cache、Rate Limiter、Online Auction、YouTube、Job Scheduler、FB Live Comments、News Aggregator、Price Tracking Service、Notification System
- Hard：YouTube Top K、Uber、Robinhood、Google Docs、Web Crawler、Ad Click Aggregator、FB Post Search、Payment System、Metrics Monitoring、Online Chess、ChatGPT、Flash Sale
- 額外 Guided Practice（無文字解答）：Food Review App、Game Leaderboard（Medium）；Donations Website、GitHub Actions（Hard）

## 面試怎麼用
- 練習時用面試會用的白板工具（先問 recruiter），別在面試中摸索工具。
- 陷阱：只讀不練；沒做過口述練習。

## 關鍵數字
- 主動練習約比被動消費多記 10 倍（原文說法）。

## 自測問題
1. 準備的兩個階段？（打地基；練習）
2. 練習的正確順序？（選題→讀需求→先自己答→再看解答→peer mock）
3. 為何要 peer mock？（口述+時間壓力是獨立技能）
